# OR Free Education

Free, open notes on Operations Research, with figures. Built with [Quarto](https://quarto.org)
and published with GitHub Pages.

- **Read the site:** https://VTMinseo.github.io/or-notes
- **Add a page:** copy a file from `_templates/`, put it in the right folder, push.
  See `CLAUDE.md` for the conventions.
- **Preview locally (optional):** install Quarto and Python, run
  `pip install -r requirements.txt`, then `quarto preview`.
